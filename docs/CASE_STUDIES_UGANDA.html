GEIDA training · Uganda · Karamoja

From Uganda's 2024 census to a plan for Moroto district

Four exercises in the browser. You start with all 2,205 subcounties of Uganda, narrow down to Moroto by attributes, then measure access to schools and health centres and screen a road upgrade. The heavy analysis runs on the course server through GeoLibre's own Whitebox tools.

PartQuestionMain tools
0Where in Uganda should a programme focus?Select by Expression, Export Selected Features
1Who lives more than 5 km from a school?Vector Points To Raster, Euclidean Distance, Reclass, Multiply, Zonal statistics
2Who lives far from a health centre, and from a proper one?The same chain, with a filter on facility level
3What would a Moroto–Tapac road upgrade cross?Buffer, Slope, Reclass, Zonal statistics (summary and class areas), Select by Location
4How do I share a result as a map?Style, Print Layout, Logo on a printed map

The projects named here are hypothetical; the data and places are real. Results under "What you should see" come from test runs on the course server in October 2026. Small differences are normal.

SETUP

Before you start

About 10 minutes, once. You need Chrome, Edge or Firefox, the access code from your trainer, and Moroto_course_data.zip unzipped on your laptop.

  1. Open GeoLibre

    Go to https://web.geolibre.app

  2. Install the Remote Processing plugin
    Settings›Manage Plugins›Settings tab

    Under Manifest URLs paste the address below and click Add. Close the dialog. The panel title should show version 0.4.0 or later; if you installed an older version, remove the URL and add it again.

    https://geolibre.terrawatch.net/plugin/plugin.json

  3. Turn it on and open the panel
    Plugins›Installed›Remote Processing, then in the top bar Remote Processing›Server connection and files
  4. Connect to the course server
    Panel tab Settings & help
    Server
    https://geolibre.terrawatch.net
    Access code
    from your trainer
    Measure in metres
    leave ticked

    Click Save and connect. The status turns green and the panel switches to the Data tab. Note your folder id (for example /data/u-7f3k9q2m1x).

  5. Check the course rasters
    Panel tab Data›Shared course data›Rasters

    You should see three rasters. They are already on the server, so you do not upload them.

    RasterContents
    moroto_dem_30m.tifElevation, Copernicus DEM 30 m: 719 m on the plains to 3,079 m on Mt Moroto
    moroto_landcover_10m.tifESA WorldCover 2021, 10 m. Classes: 10 tree cover, 20 shrubland, 30 grassland, 40 cropland, 50 built-up, 60 bare, 80 water, 90 wetland
    moroto_population_2024_100m.tifWorldPop 2024 (constrained): people per 100 m cell

Vector files in the zip

Open each with Add Data›Vector Layer and choose the file. They do not need uploading: GeoLibre sends a map layer to the server with each job. The four national boundary files are also in the panel under Shared course data›Vectors: click Add to map.

Districts, subregions, regions and the outline were made by dissolving the census subcounties, so all levels line up exactly. Their pop_total is the sum of the subcounties: it leaves out Bidi Bidi settlement and the five Nakapiripirit subcounties without figures.

How to run any Whitebox tool on the server

Every Whitebox step below follows the same pattern:

  1. Open the toolbox and find the tool
    Processing›Whitebox Toolbox, type the tool name in the search box, click it.
  2. Untick Run locally (WASM)

    Top right of the dialog. If it stays ticked, the tool runs on your laptop and cannot read the server files.

  3. Fill in the inputs

    Raster input: set the drop-down to Path and paste a server path. Use Copy path next to a file in the panel's Data tab, or the paths given below. Vector input: pick the layer from the drop-down.

  4. Name the output and run

    Type the short name given in the step (for example dist_school) or leave Auto. Click Run and wait for Succeeded. The result appears in your folder in the Data tab.

Paths in your folder

Outputs are saved as /data/<your folder>/<name>.tif. When a later step says "Input dist_school.tif", use Copy path on that file in the Data tab.

PART 0

From Uganda to Moroto

Where in Uganda should an education and health access programme start? Selecting by attributes.

Context

A (hypothetical) Karamoja Education and Health Access Programme must choose one district for its first phase. The evidence is the 2024 census at subcounty level.

  1. Build the context: country, regions, subregions, districts
    Add Data›Vector Layer, or the panel's Shared course data›Vectors

    Load uganda_country, uganda_regions, uganda_subregions and uganda_districts. Click each one and compare pop_total and n_subcounties: Karamoja has 1.43 million people in 113 subcounties.

    Style them as outlines so they work as a frame: open the layer's style (Style tab on the right, or the palette icon in the Layers panel), set the fill opacity to 0 and give each level its own line: thick dark for regions, medium for subregions, thin grey for districts. Drag them to the top of the Layers panel.

  2. Load the national subcounties
    Add Data›Vector Layer

    Choose uganda_subcounties_census2024.geojson. 2,205 subcounties appear, below the boundary outlines.

  3. Explore the attributes

    Click a few subcounties and read pop_total, pct_oos612 (share of children 6–12 out of school), pct_watimp (improved water) and pct_grid (grid electricity). Every field is explained in Census attributes.

    Optional: colour the layer by pct_oos612 from its style settings (palette icon in the Layers panel) to see the national pattern.

  4. Select the Karamoja subregion
    Edit›Select by Expression...
    Select features from
    uganda_subcounties_census2024
    Expression
    ["==", ["get", "Subregion"], "Karamoja"]
    Modify selection by
    Creating a new selection

    Click Select features. The dialog reports 113 of 2205 features selected.

    Expressions use MapLibre's JSON form: ["operator", ["get", "field"], value]. The Expression builder... button helps you write them.

  5. Keep only subcounties with more than 70% out of school
    Same dialog
    Expression
    [">", ["get", "pct_oos612"], 70]
    Modify selection by
    Selecting within the current selection

    Click Select features: 67 selected, and 6 could not be evaluated.

  6. Look at the result
    Edit›Zoom to Selection
  7. Choose Moroto and make it a layer
    Edit›Select by Expression..., then Edit›Export Selected Features as Layer
    Expression
    ["==", ["get", "District"], "Moroto"]
    Modify selection by
    Creating a new selection

    9 subcounties are selected. The same selection works one level up: ["==", ["get", "District"], "Moroto"] on uganda_districts gives the district outline, and ["==", ["get", "Subregion"], "Karamoja"] on uganda_subregions the subregion. The exported layer is your study area. You can also load moroto_subcounties_census2024.geojson, which is the same.

Discuss

  • Why Moroto rather than Amudat (86% out of school)? Think about data coverage (OpenStreetMap has 66 schools and 38 health facilities in Moroto), the terrain of Mt Moroto for Part 3, and the contrast between town and rural subcounties.
  • What does a missing value do to a selection? Try ["==", ["get", "pop_total"], null]
  • Try Filter layer instead of Select features. What is the difference?
PART 1

Who lives far from a school?

How many people in each Moroto subcounty live more than 5 km from a school, and does distance line up with out-of-school rates?

Context

The programme wants to know where new classrooms would bring the most children within walking distance (5 km).

Schools (points)→Vector Points To Raster→Euclidean Distance→Reclass > 5 km→Multiply × population→Zonal statistics per subcounty
  1. Load the layers
    Add Data›Vector Layer

    Load moroto_schools_osm.geojson and moroto_subcounties_census2024.geojson (or use your exported Moroto layer).

  2. Burn the schools onto the population grid
    Whitebox tool Vector Points To Raster
    Input
    the schools layer (drop-down)
    Base
    Path /data/moroto_population_2024_100m.tif
    Zero background
    ticked
    Output
    school_r

    Using the population raster as the base puts every later raster on the same 100 m grid, so they can be combined cell by cell.

  3. Distance to the nearest school
    Whitebox tool Euclidean Distance
    Input
    Path to school_r.tif (Copy path in the Data tab)
    Output
    dist_school

    Each cell now holds the straight-line distance in metres to the nearest school.

  4. Mark cells beyond 5 km
    Whitebox tool Reclass
    Input
    Path to dist_school.tif
    Reclass values
    0;0;5000;1;5000;1000000
    Output
    far_school

    Read the values in groups of three: new value; from; up to. Cells 0–5,000 m become 0, cells beyond 5,000 m become 1.

  5. Count the people beyond 5 km
    Whitebox tool Multiply
    Input 1
    Path to far_school.tif
    Input 2
    Path /data/moroto_population_2024_100m.tif
    Output
    pop_far_school
  6. Summarise per subcounty
    Panel Data›Zonal statistics (open the section)

    Run it three times, with Zones = the Moroto subcounties layer and Also download the table as CSV ticked:

    RasterField prefixRead
    dist_school.tifdist_dist_mean: average distance (m)
    pop_far_school.tiffar_far_sum: people beyond 5 km
    Shared moroto_population_2024_100m.tifpop_pop_sum: all people (WorldPop)
  7. Compare in a spreadsheet

    Open the CSVs. Compute far_sum / pop_sum for each subcounty and set it beside the census field pct_oos612.

Discuss

  • Rupa's mean distance is 28.5 km, yet only 30% of its people are beyond 5 km. Why? (Large empty areas; people live near the schools.)
  • Lotisan has 80% out of school but nobody beyond 5 km. Which other barriers matter there?
  • WorldPop puts about 130,000 people in Moroto; the census counts 103,639. Which would you use, and for what?
PART 2

Who lives far from a health centre?

Which subcounties lack access to a health centre that offers more than basic care (HC III and above)?

Context

The district health office plans outreach and new health centres. Uganda's facility levels run from HC II (basic) through HC III and HC IV to hospitals.

  1. Load and inspect the health facilities
    Add Data›Vector Layer

    Choose moroto_health_facilities_osm.geojson and click a few points. The level field was derived from the names, because OpenStreetMap tags every facility in Moroto as "hospital" and several were mapped twice (57 points became 31).

  2. Run the access chain for all facilities

    Repeat Part 1 steps 2–6 with the health facilities layer. Use the outputs health_r, dist_health, far_health and pop_far_health.

  3. Select HC III and above
    Edit›Select by Expression... on the health facilities layer
    Expression
    ["in", ["get", "level"], ["literal", ["HC III", "HC IV", "Hospital"]]]

    Click Select features: 16 of 31 selected. Then Edit›Export Selected Features as Layer.

  4. Run the chain again for HC III and above

    Repeat Part 1 steps 2–6 with the exported layer. Use the outputs health3_r, dist_health3, far_health3 and pop_far_health3.

PART 3

Screening a road upgrade: Moroto town to Tapac

What terrain, land cover and people does a corridor of 1 km on each side of the road cross?

Context

Tapac is the least served subcounty in Parts 1 and 2. A (hypothetical) Moroto–Tapac Rural Access Road would upgrade the existing 27 km track, which runs along the foothills of Mt Moroto.

Road line→Buffer 1 km→Slope, Reclass > 15°→Zonal statistics: class areas and summary→Select by Location

    Add Data›Vector Layer

    Load moroto_tapac_road.geojson, plus the schools and health facilities if they are not on the map yet.

  2. Make the corridor

    Click Run. A Buffer layer appears. This tool runs in your browser and is instant for one line.

  3. Slope from the DEM

    Input

    Units

    Whitebox tool Reclass
    Input
    Path to slope.tif

    Zones

    Click Run zonal statistics on the server. In one run the corridor gets, for every class, its area in km² and its share in %: lc_grassland_km2, lc_grassland_pct, lc_shrubland_pct, lc_cropland_pct and so on. Click the new Class areas layer on the map to read them, or open the CSV.

PART 4

Print a result as a map, with the IsDB logo

Turn the Part 1 result into a map you can put in a report: out-of-school children and distance to school in Moroto.

  1. Prepare the layers

    Keep on the map: the Part 1 zonal statistics layer for pop_far_school (the subcounties with far_sum), the schools, uganda_districts as context and a light basemap. Hide everything else with the eye icon in the Layers panel.

  2. Colour the subcounties by a value
    Select the zonal statistics layer, then the Style tab on the right

    Choose the Graduated style on pct_oos612 with 5 classes and a yellow-to-red ramp. Set fill opacity to about 0.8. For the schools use small dark circles; for the districts a thin grey outline with no fill.

    Rename the layers from the ⋯ menu next to each layer in the Layers panel, for example "Children 6–12 out of school (%)" and "Schools (OSM)". The legend uses these names.

  3. Frame the map

    Zoom to Moroto district (Edit›Zoom to Selection on the Moroto subcounties works well) and turn the map to north up.

  4. Open the print layout
    Project›Print Layout...
    Title
    Moroto district: children out of school and distance to school
    Subtitle
    Share of children aged 6–12 out of school, by subcounty (NPHC 2024)
    Size, orientation
    A4, Landscape
    Map elements
    tick Legend, Scale bar, North arrow, Date and Footer text
    Footer text
    Data: UBOS NPHC 2024; OpenStreetMap contributors; WorldPop 2024. GEIDA training, IsDB.

    Check the preview on the right. If you changed the map, click Recapture map. Untick legend entries you do not need with the eye icons in the Legend section.

  5. Export the map

    Click Export PNG. The file is saved to your Downloads folder.

  6. Add the IsDB logo
    Panel Data›Logo on a printed map (open the section)
    Exported map (PNG)
    the PNG you just exported
    Logo
    leave empty for the IsDB logo, or choose your own PNG
    Corner
    Bottom right (or a corner the legend does not use)
    Logo width
    16 % of the page

    Click Add logo and download. You get …-logo.png, the same map with the logo on a white box.

Why a separate step for the logo?

GeoLibre's Print Layout has no image element yet. Controls›Image can place a logo on the screen map (Image URL https://geolibre.terrawatch.net/plugin/assets/isdb-logo.png), which is fine for screen sharing, but the print layout leaves it out. The plugin adds it to the exported PNG instead.

Discuss

  • Which map tells the story better: out-of-school share or people beyond 5 km? Make both and compare.
  • What should every map in a report carry? (Title, legend, scale, north arrow, source, date, author.)
FIELDS

Census attributes

What each field in uganda_subcounties_census2024 and moroto_subcounties_census2024 means.

Figures are from the Uganda Bureau of Statistics, National Population and Housing Census 2024, published in the NPHC 2024 Explorer (subcounty profiles). Counts are persons or households as noted; fields starting with pct_ and pop_dens were derived from them for the course. Field names are 10 characters or fewer so they also work in shapefiles.

Used in the exercises

Subregion, District, pop_total, pop6_12, oos6_12, pct_oos612, data_note. Useful for your own questions: pct_watimp, pct_sanimp, pct_grid, pct_noecce, neet1524p, hh_pdm.

Read the data critically

OpenStreetMap is incomplete and the health facilities were cleaned. WorldPop and the census disagree on Moroto's population. The UBOS boundaries are simplified and overlap slightly along district borders.
