GeoLibre processing server

This server runs GeoLibre's Whitebox tools and zonal statistics for course participants. You do not use it directly: you work in GeoLibre in your browser, and the Remote Processing plugin connects to this server.

  1. Open GeoLibre:
    Open web.geolibre.app
  2. Install the plugin: Settings > Manage Plugins > Settings tab, paste this under Manifest URLs, click Add:
  3. Turn it on: Plugins > Installed > Remote Processing, then Remote Processing > Server connection and files.
  4. Enter the server address and the access code from your trainer, then Save and connect.

Course data and guide

Download the data and unzip it on your laptop. Open the vector files in GeoLibre with Add Data > Vector Layer. The rasters are already on this server (plugin Data tab > Shared course data).
